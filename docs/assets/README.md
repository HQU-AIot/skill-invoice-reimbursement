# 演示素材目录

README 会引用以下文件；录制/截图后放在本目录：

| 文件 | 用途 | 建议规格 |
|---|---|---|
| `demo.mp4` | 完整演示视频 | 1080p，16:9，3–5 分钟，H.264，≤ 50 MB |
| `cover.png` | 视频封面 / README 头图 | 1280×720，≤ 500 KB |
| `screenshot-folder.png` | 目录结构截图 | 宽度 ≥ 1200 px |
| `screenshot-workbook.png` | 财务报表截图 | 宽度 ≥ 1200 px |
| `screenshot-audit.png` | 终审 PASS 输出截图 | 宽度 ≥ 1200 px |

当前仓库已包含一个可直接使用的 `cover.svg`，README 目前用它作为封面；上传 `cover.png` 后可以把 README 的图片地址换成 `cover.png`。

## 录制前必读

- 不要出现真实单位名称、税号、发票号码、订单号、姓名、电话、地址。
- 建议使用 `examples/` 的虚构数据，或对真实界面做模糊/遮挡。
- 视频里不要展示浏览器登录态、聊天窗口、桌面其他文件。
- 上传前用播放器逐帧检查一遍，确认没有敏感信息闪现。

视频分镜和旁白见 [`../演示视频脚本.md`](../演示视频脚本.md)。
